# Snavigation（优化版）

简洁的浏览器导航起始页。零外部依赖、零构建步骤，可直接静态托管或以 `file://` 本地打开。

[原项目](https://github.com/imsyy/Snavigation) · [Github Pages](https://ltgxs.github.io/Start)

## v1.7 更新（第五轮优化）

**新功能与新卡片**（以下均可在 设置 → 偏好 中开关，即改即存即生效）

- **一言卡片**：搜索框下方新增玻璃质感语录卡。hitokoto.cn 主备双源在线取句，离线 / 接口不可用时回落内置 10 条经典语录；上次内容先秒开展示、后台静默换新。点击卡片复制全文（Clipboard API，旧环境回退 execCommand），右侧 ↻ 换一条。进入搜索态 / 打开面板时淡出让位，矮屏（<640px 高）自动隐藏
- **倒数日**：日期下方新增小胶囊，「距 期末考试 还有 45 天」「就是今天 🎉」「已过去 N 天」三种形态，倒数与纪念日两用；跨天由时钟心跳自动更新（带渲染缓存，内容不变不动 DOM）；点击胶囊直达设置编辑
- **搜索历史**：本地记录最近 8 条搜索（去重置顶），聚焦空搜索框时展示；方向键可在历史词间循环（含"空输入"位）、悬停显示单条删除 ✕、面板头部一键清空；默认开启，可在偏好中关闭或清除；数据仅存本地
- **偏好设置选项卡**：设置面板新增第 5 个选项卡「偏好」，集中管理一言卡片 / 时钟秒 / 背景视差 / 启动问候 / 搜索历史 / 倒数日
- **时钟显示秒**：可选 HH:MM:SS，开启后按秒边界对齐调度，关闭时维持原有的 1 次/分唤醒；小屏字号自适应收窄
- **背景视差**：背景随鼠标位置反向轻移（CSS 变量 + rAF 节流 + 0.25s 阻尼），触屏设备与系统「减少动态效果」偏好下自动停用
- **书签卡片阶梯入场**：打开书签面板（或切换 Tab）时卡片按序号错峰滑入（22ms/张，上限 380ms），遵循减少动态效果偏好

**修复的 Bug**

- 收起的面板只是透明并未"离场"：书签 / 设置面板、引擎下拉、面板态下的搜索框里几十个链接、按钮、输入框全部留在 Tab 焦点序与无障碍树中，键盘用户会依次聚焦到一整片看不见的控件。现以 `inert` 属性随开合统一移出（不支持的老浏览器自动退化为旧行为）。开发中曾尝试纯 CSS `visibility` 方案，实测与全局 `transition: all` 相互作用：后代继承的 visibility 变化会被挂在过渡起点上，刚打开的面板内容有概率瞬时不可聚焦，故弃用
- 搜索引擎下拉"能打开、不能选"：列表项是纯 div，键盘用户按 Enter 打开面板后无法选中任何引擎；现每项可 Tab 聚焦、Enter / 空格选择，配焦点环
- 主页「+ 添加快捷方式」是无 href 的 `<a>`，不进焦点序，键盘无法从主页发起新增；补 tabindex 与键盘触发
- 删除搜索历史单条时整个面板闪退：内层处理器先重渲染列表，事件冒泡到全局"点击面板外收起"逻辑时目标节点已被摘除，`contains` 判定失效被误判为外部点击；现检查 `isConnected` 并在删除路径阻断冒泡
- 天气详情展开面板 `max-height: 120px`，窄屏下四个指标折行后被裁掉下半截；放宽至 240px
- 确认框把焦点抢到自己按钮上，关闭后焦点落回 body，键盘用户回不到刚才操作的位置；现记录并归还焦点（元素已随重渲染消失时自动跳过）
- 浅色主题下天气行的「°C ~」等直书文字仍用写死的 #efefef，泛白难读；改用主题变量
- 搜索态下输入框底色变白而占位符仍是主题浅色，深色主题里呈"白底白字"幽灵残影；搜索态单独配色
- 关闭背景视差的瞬间，已排队的 rAF 帧仍会把旧偏移写回（归零后背景又跳一下）；回调内二次校验开关
- 面板打开时按 `/` 会聚焦到被面板盖住的搜索框，进入错乱的复合状态；现先逐层关闭面板再聚焦

**其他**

- 数据导入白名单纳入偏好设置与搜索历史：偏好逐字段校验类型（未知字段丢弃、倒数日日期须为合法 YYYY-MM-DD），历史仅接受字符串数组并截断至上限
- Service Worker 升版 v1.7.0，缓存清单纳入 `js/widgets.js`（一言 / 倒数日 / 视差新模块）
- 以上改动通过无头 Chromium 的 63 项自动化冒烟测试（外部 API 全部 mock：天气 / 联想 / 一言 / 各壁纸源，含壁纸竞态、历史增删清空、偏好持久化、导入清洗与上四轮全部回归项），连续多轮运行零失败

## v1.6 更新（第四轮优化）

**新功能与增强**

- 离线可用与秒开：新增 Service Worker（`sw.js`）。页面导航网络优先（3s 超时回落缓存），CSS / JS 走 stale-while-revalidate（缓存秒开、后台更新、下次生效），字体 / 图片缓存优先，跨域 API 一概不拦截。断网或弱网时起始页照常打开；`file://` 与纯 http 环境自动跳过注册，行为不变
- PWA 安装性补全：生成并接入 192 / 512 图标（Chrome 的可安装判据要求 ≥192px，此前最大只有 144px，安装提示可能根本不出现），iOS 侧补 180px `apple-touch-icon`
- 新快捷键 `R`：换一张壁纸（等同右上角刷新按钮），快捷键面板同步补充说明
- 联想词方向键循环加入「原始输入位」：越过最后一条（或从第一条向上）时恢复自己键入的词，而非硬性跳到另一端，与主流搜索框一致
- 下拉选完搜索引擎后光标自动回到输入框：此前会停在"搜索态但无焦点"的悬空状态，得再点一次才能打字
- 确认框键盘可达：弹出后确认按钮自动获得焦点（延迟 250ms，防止按住回车保存时的按键连发误触确认），回车确认、Tab 切到取消、Esc 取消
- 快捷键面板点击暗色遮罩即可关闭（此前只认 `?` / `H` / `Esc`）
- 壁纸类型单选恢复键盘可达：此前用 `display:none` 隐藏，被整体移出 Tab 序与无障碍树，键盘用户完全无法切换壁纸；改为视觉隐藏（clip-path），配 `:focus-visible` 焦点环。同时为时钟 / 天气 / 主题 / 刷新 / 设置 / 引擎切换等自定义按钮补上统一的键盘焦点环
- `<meta name="theme-color">` 跟随手动主题：此前只按系统深浅色切换，手动强制浅 / 深主题时浏览器标题栏与 PWA 窗口色不跟着变
- 书签悬停提示：显示完整名称与域名，名称被省略号截断时也能看全
- 欢迎问候等待首次天气结果（上限 2.5s）：此前固定 800ms 露面而天气几乎不可能这么快返回，「当前 xx°C」的问候形同虚设，永远只显示兜底文案
- 关闭设置 / 书签面板时若焦点仍留在面板内部控件上则主动释放，避免键盘焦点困在不可见区域

**修复的 Bug**

- 快捷方式全部删光后「复活」：空对象 `{}` 被当作数据损坏，下一次读取即重新灌入预设——刚提示"删除成功"，五个预设整队回归。现在空列表是合法状态（搜索引擎列表因搜索必须可用，维持非空回落）
- 编辑默认搜索引擎并修改其序号后，默认标记仍指向已不存在的旧键，随后的自愈回落把默认引擎悄悄改成列表第一项；现在默认标记跟随条目迁移
- 含固定参数的自定义引擎搜索时参数被静默丢弃：GET 表单提交会用表单数据整体替换 action 里的查询串（如 `…/search?tbm=isch` 的 `tbm` 直接消失）。现将 action 原有参数拆成隐藏字段随表单提交，切换引擎时旧注入字段同步清理
- 壁纸快速连续切换的竞态：先发但网络较慢的旧请求可能最后返回，把已选定的新壁纸又盖回旧的（v1.5 只抑制了过期 Toast，没拦截应用本身），旧请求还会把旧图写进新配置的缓存造成"元数据与图数据错位"。现引入加载代际令牌，旧代际的应用与缓存写入一律作废
- 壁纸抓取此前用裸 `fetch` 没有超时：网络挂起时手动刷新的加载动画永远转圈、刷新按钮从此失效；现统一 10~20s 超时兜底
- 「失败时保留当前背景」名不副实：新壁纸加载失败的收尾逻辑会无条件重走回退链，把好端端的当前背景换成兜底图；现在当前图健康时不再动它
- 坏地址被记为「上次壁纸」：记录此前在加载发起前写入，失败地址也会被记住，之后每次启动都先展示坏地址、失败、再回退，白白闪一下；现在只记录真正加载成功的图
- 起始页躺在后台标签页时浏览器会把定时器节流到近乎停摆，切回前台天气可能已陈旧数小时且下次轮询遥遥无期；现在切回时若超过正常刷新周期立即补拉
- 「正在打字」判定过宽：焦点落在单选 / 复选框上时（如点过"每次刷新更换背景"）所有单键快捷键被吞，`S` / `T` / `B` 全部失灵；现在仅文本类控件计入打字状态
- 关闭设置时新增 / 编辑表单的半填内容此前只是被藏起来，下次打开表单残稿仍在；现在回到列表视图时表单值一并清空

**其他**

- 清理确认无引用的死代码样式（`.wallpaper_cache_save` 三组、`.noclickn`、`img.error`、`@keyframes down`、`.configure-core`）
- 以上改动通过无头 Chromium 的 87 项自动化冒烟测试（外部 API 全部 mock，含壁纸竞态的双色图判定、Service Worker 断网重载、导入导出往返、以及上三轮修复点的回归项），连续多轮运行零失败

## v1.5 更新（第三轮优化）

**新功能与增强**

- 壁纸「选择即生效」：设置里切换壁纸类型、或保存自定义 URL 后，立即交叉渐变换上新图，不再要求刷新页面。带加载中 / 失败提示（失败时保留当前背景不白屏），连续快速切换以代际计数抑制竞态，只有最后一次选择落地；选项说明文案同步改为"切换后立即生效"
- 页面可作为 PWA 安装：新增 `manifest.json`（独立窗口、主题色、多尺寸图标）并在 `index.html` 引用
- 原生控件配色随主题：声明 `color-scheme`，滚动条、日期控件等浏览器原生 UI 在深 / 浅主题下不再突兀
- 数据导入白名单加入主题设置（带取值校验，仅接受 auto / light / dark），备份恢复后主题一并还原
- 键盘可达性补全：搜索引擎切换按钮与时钟（书签开关）现在可 Tab 聚焦、回车触发，并补齐 `role` 与 `aria-label`
- API 密钥输入框标注 `autocomplete="new-password"`，避免浏览器把密钥误存进密码管理器

**修复的 Bug**

- 「每日必应」等远程壁纸永不更新：换图判定只看 IndexedDB 里有没有缓存图，从不检查 `cacheDuration` 是否已过期，配置的缓存时长形同虚设；现在过期即触发换新并续期
- 搜索态下联想框与搜索框脱节约 61px：搜索框上移 140% 时引擎下拉此前已做位移补偿，联想框被遗漏、悬在原位；补上对应偏移后紧贴搜索框
- 失效的远程壁纸地址会被缓存 24 小时，期间每次加载都命中坏地址反复失败；现在加载失败即清除缓存元数据，下次访问重新取图。同时修复"同图跳过"判断把**加载失败**的 src 也当成"已在展示"、短路掉重试与缓存清理路径的问题（跳过现要求当前图确实解码成功）
- 可以保存"字段名"为空或含空格 / `=&#?` 的搜索引擎——空 name 的输入框不随表单提交，搜索词根本带不进 URL，等于存了个废引擎；引擎与快捷方式的空名称同样被放行。现均校验并给出提示
- 设置面板开着表单时直接关闭再重开，半填的表单残留、列表被隐藏；关闭时统一复位表单与列表
- wttr.in 天气备源请求缺 `lang=zh` 参数，代码里读取的 `lang_zh` 字段从不存在，备源生效时天气描述只能显示英文
- 问候语把"今日最低温"当作当前温度展示；现两个天气源均补充真实当前温度字段
- 确认框弹出时按 `Esc` 会穿透关掉下层设置面板，确认框本身却纹丝不动；现在 `Esc` 优先取消确认框且不再穿透
- 默认搜索引擎的存储键失效（如导入的数据不含该键）时，高亮指向幽灵项且搜索行为异常；现自动回落到列表第一项并回写存储
- 鼠标中键点击天气 / 时钟区域会误触"切换书签"（该区域此前不在中键劫持的排除列表内）
- emoji 开头的标题生成字母头像时按 UTF-16 码元截取，代理对被截成半个乱码；改按完整字符截取
- 壁纸适配模式快速关闭又开启时，上一次关闭的收尾定时器会把刚显示的氛围层重新藏掉；定时器现在会被新一轮操作清除
- 本地壁纸缓存到期换新有 1/10 概率随机到当前同一张，"换了个寂寞"；到期换新现与手动刷新一样排除当前图
- 深色下选中文字的 `::selection` 样式近乎不可见（深底配黑字）；重写为半透明高亮且不改文字颜色，浅色主题另配
- 序号输入框占位文案写"小于 20"，实际允许填 20；改为"1 ~ 20 的正整数"（快捷方式同理修正为 1 ~ 99）

以上改动通过无头 Chromium 的 52 项自动化冒烟测试（覆盖本轮全部修复点、上两轮的回归项、离线降级与刷新后状态保持），连续多轮运行零失败。

## v1.4 更新（第二轮优化）

**新功能**

- 浅色 / 深色主题：右上角新增主题按钮（或按 `T`），在「跟随系统 → 浅色 → 深色」间循环，选择持久保存。CSS 中的浅色主题此前是从未被启用的死代码，本次接通并补齐 Toast、暗角、下拉高亮等浅色场景的样式，另修复了写错的 `.onsearch.light-theme` 选择器（两个类分属 html 与 body，原写法永不匹配）
- 搜索引擎「选择即记住」：下拉中点选的引擎立即生效并持久化，下拉内高亮当前引擎；设置里"设为默认 / 重置"不再整页刷新
- 快捷键补全：`Esc` 现在按「快捷键面板 → 下拉/联想 → 设置 → 书签 → 搜索态」逐层关闭（此前面板上写着"关闭弹层"但只关快捷键面板）；`S` / `B` 变为开关式；新增 `T` 切换主题；`Ctrl / Alt / Meta` 组合键不再被单键快捷键误吞
- 表单内回车即保存（引擎 / 快捷方式 / 自定义壁纸 URL）
- 书签图标三级回退：谷歌 s2 失败后先尝试站点自身 `/favicon.ico`，再降级字母头像（谷歌服务不可达的网络环境下不再直接全变字母）
- 天气图标补充雷 / 雾 / 霾 / 沙尘；接口增加 10s 超时；备源成功后按 30 分钟正常节奏轮询（原先只要主源失败就永远 5 分钟一次）

**修复的 Bug**

- 中文输入法：组合期间不再发起联想请求（原 keyup 监听会为拼音过程逐键请求）；组合中的回车 / 方向键不再触发提交或候选切换
- 通过 Tab / 快捷键聚焦搜索框后回车，空查询会直接提交到搜索引擎（原判断依赖点击才添加的 class）；现按提交事件兜底并自动去除首尾空白
- 书签 / 设置面板打开时，透明化的搜索框仍然可点（z-index 高于遮罩），误触会进入错乱的搜索态
- `Esc` 退出搜索后输入框仍持有焦点，导致所有单键快捷键失效
- 编辑「百度 / 必应 / 谷歌」等预设引擎会把图标覆盖成通用网络图标
- 编辑默认引擎的 URL 后，关闭设置不刷新表单 action，搜索仍指向旧地址
- 序号输入 `+5` 会以字符串键 `"+5"` 存储，与 `"5"` 并存为两条
- 时钟每分钟整块重写 innerHTML，冒号闪烁动画随之重启，出现肉眼可见的跳变；现只更新文本节点，并在从后台标签页切回时立即校时
- 本地壁纸的"同图跳过"判断用相对路径与 `img.src` 的绝对地址比较，永远判不相等，同一张图被反复交叉渐变；并发换图（初始化与手动刷新重叠）时旧一轮的收尾定时器会打断新一轮过渡，现引入代际令牌
- 默认壁纸手动刷新后缓存元数据仍指向旧图；壁纸设置里点击"已选中"的选项也会误清缓存与上次壁纸记录（现在只查看说明）
- 鼠标中键在输入框 / 面板 / 按钮上都会被劫持成"切换书签"，Linux 下的中键粘贴完全不可用；现仅在空白背景生效
- 全局 `user-select: none` 连输入框文字都无法选中，编辑长 URL 十分困难
- JSONP 超时后若响应迟到，会因回调已删除抛"not a function"
- `localStorage` 写入未捕获异常，隐私模式 / 配额满时会中断脚本
- 首屏背景恢复的内联脚本未过滤引号，构造过的 URL 可注入 CSS；现遇可疑字符直接放弃恢复
- README 声称的字体 preload 实际缺失，本次补上（同源字体 preload 需带 `crossorigin`）

**性能与体验**

- 加载屏滑出后彻底 `visibility: hidden`：原先两块带 `backdrop-filter` 的图层只是移出屏幕，持续占用合成资源
- 引擎下拉高度自适应（引擎少时不再留大片空白），联想框限高可滚动
- 遵循系统「减少动态效果」偏好；矮屏下面板自动上移并限高
- 自定义按钮（天气 / 主题 / 刷新 / 设置）支持 Tab 聚焦与回车 / 空格触发
- 补充 `theme-color`、PNG 图标与 `apple-touch-icon`（此前 `img/icon/` 下的资源从未被引用）

以上全部改动已通过无头 Chromium 的 31 项自动化冒烟测试（含离线降级、刷新后状态保持）。

## 首轮优化摘要

**体积**：9.4MB → 约 2.1MB（-78%）

- 移除未被 CSS 引用的 4MB 全量字体与 1.6MB TTF 子集（页面实际只用 888KB 的 woff2 子集）
- 移除 1.4MB 彩蛋视频与引用缺失脚本的 `indx.html`
- 移除 iconfont 的 ttf / woff 回退（现代浏览器均支持 woff2）

**外部依赖**：3 个 CDN 请求 → 0

- jQuery → 原生 JS（`js/utils.js` 内约 40 行 DOM 助手）
- iziToast（CSS+JS）→ 自研 Toast / Confirm 组件（`utils.js` + `style.css`），风格与站点一致
- js.cookie.js → 15 行内联 Cookie 迁移逻辑（仅用于老数据一次性迁移）

断网 / CDN 故障时页面本体功能不再受影响。

**可维护性**

- 新增 `js/config.js` 作为唯一配置源。原先壁纸预设、存储键、壁纸源地址与描述文案分别在 2~3 个文件中重复定义，现全部收敛
- 「开发 / 学习」静态书签从约 150 行 HTML 移入 `config.js` 的 `STATIC_TABS` 数据，与用户书签共用同一渲染函数；新增 Tab 只需追加一段数据
- 壁纸模块以 async/await 重写，删除 106 处调试日志；两处重复的按类型加载分支合并为 `loadWallpaperByType()`
- 各模块通过 `App.initXxxModule()` 在 `main.js` 中按显式顺序启动，依赖关系一目了然

**修复的问题**

- 在输入框打字时按 `h` / `?` 会误触快捷键面板（缺少输入态判断）
- 图片加载失败时的回退链会被立即恢复的旧 onerror 覆盖，导致多级回退失效
- 调试开关在 localStorage 异常时反而默认开启
- 快捷方式表单读取不存在的 `img` 字段，存入 `undefined`
- 两处 `document.write`（阻塞解析且已被浏览器弃用）：首屏背景恢复改为同步注入 CSS 自定义属性 `--boot-bg`，页脚年份改为 `textContent`

**性能**

- 时钟从每秒重写 DOM 改为按分钟边界对齐更新（页面只显示到分钟），唤醒次数降为 1/60
- 脚本全部 `defer`，字体 `preload` + `font-display: swap`
- 搜索引擎下拉宽度由 JS 计算改为纯 CSS 定位，消除打开时的强制布局
- 删除页面加载后追加下载 4MB 全量字体的逻辑

## 常见修改

- 增删静态书签 Tab：编辑 `config.js` 中 `STATIC_TABS`
- 更换默认搜索引擎 / 快捷方式预设：编辑 `SE_PRESET` / `QUICK_PRESET`
- 调整偏好默认值（一言 / 秒 / 视差 / 问候 / 历史）：编辑 `PREFS_PRESET`
- 更换一言离线语录 / 接口：编辑 `HITOKOTO_FALLBACK` / `HITOKOTO_API`
- 调整搜索历史条数上限：编辑 `SEARCH_HISTORY_MAX`
- 调整壁纸源或说明文案：编辑 `WALLPAPER_SOURCES`
- 调整背景渐变时长、缓存上限：编辑 `BG_CONST`
- 部署后改动 css / js：无需额外操作——SW 对 css / js 采用 stale-while-revalidate，用户下下次访问自动拿到新版；若希望立刻强制丢弃全部旧缓存，改一下 `sw.js` 顶部的 `VERSION` 即可
